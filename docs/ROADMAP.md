## 下一版本计划

- **目标**：让任意已接入的模型在对话快到容量上限时，能自动整理旧内容并继续工作，避免因“整段历史原样带入”而卡住。
- **做**：
  1. 核验 DSH 当前的对话组装与模型容量判断位置；
  2. 设计跨模型的触发规则、摘要格式、失败降级和用户提示；
  3. 实现自动压缩、回归测试、独立质量检查与安全审查；
  4. 提供可关闭、可追溯的安全开关，避免静默丢失重要信息。
- **不做**：
  - 不把这项通用能力伪装成 ChatGPT 绑定插件的功能；
  - 不修改或删除用户的原始对话记录；
  - 不以简单截断历史代替摘要。

## 验收标准

- 在接近不同模型容量上限前自动触发，而不是等请求卡死；
- 压缩后保留用户目标、已确认决定、当前任务、关键约束与近期上下文；
- 摘要失败时不丢原内容，并给出明确、可恢复的提示；
- 覆盖 ChatGPT 路由及其他 DSH 模型路由；
- 有自动化测试证明不会重复压缩、不会无限重试、不会泄露私密内容。
