# PRD：DSH 模型运行守护（MVP）

## 背景与目标

用户在使用 DeepSeek Harness 时遇到两类高频问题：  
1. 对话接近容量或模型长时间无有效输出时，缺少可见、安全的自动整理与恢复；  
2. DSH 自发布以来积累了若干公开问题与第三方网关兼容性问题，缺少一份结构化、可查阅的清单。

本 MVP 只做两件事：  
- 一个独立的自动上下文压缩插件；  
- 一份保存到下载目录的 DSH 已知问题 Markdown 清单。

## 目标用户

使用 DSH 做长时间开发、研究或多轮协作的个人开发者，无技术背景，不希望接触代码或配置细节。

## 功能需求

### FR-1 自动上下文压缩插件

- **描述**：为 DSH 提供一个可独立加载的自动压缩插件，在对话接近模型容量时自动生成摘要并替换早期历史，保留最近对话。  
- **验收标准**：  
  - Given 插件已加载且路由已配置阈值，When 当前会话估算 token 达到该路由阈值，Then 自动触发压缩并在 UI 显示“正在整理历史”；  
  - Given 压缩成功，When 摘要生成完成，Then 早期历史被替换为摘要，最近历史保留，UI 显示“已整理 N 条历史”；  
  - Given 压缩失败，When 摘要超时或返回空/非缩小内容，Then 保留原历史，UI 显示“整理失败，已保留原内容”，不静默继续超额请求；  
  - Given 插件未加载或未配置阈值，When 会话增长，Then 不影响现有 `dsh-compaction-basic` 行为。

### FR-2 按路由可调压缩阈值

- **描述**：支持为不同模型路由配置不同的触发阈值与保留比例。  
- **验收标准**：  
  - Given 配置文件指定 `openai-codex` 阈值为 70%，When 该路由会话达到 70% 容量，Then 触发压缩；  
  - Given 配置文件指定 `opencode-go/deepseek-v4-pro` 阈值为 65%，When 该路由会话达到 65% 容量，Then 触发压缩；  
  - Given 未配置的路由，When 会话增长，Then 使用默认 80% 阈值。

### FR-3 摘要安全降级

- **描述**：压缩失败时不丢失原始历史，不调用无限重试。  
- **验收标准**：  
  - Given 摘要模型返回空文本，When 压缩事务提交前校验，Then 中止提交，保留原 surface，记录警告；  
  - Given 摘要后 token 数未减少，When 校验发现未缩小，Then 中止提交，保留原 surface；  
  - Given 同一会话连续两次压缩失败，When 第三次触发，Then 不再自动尝试，仅提示用户手动 `/compact`。

### FR-4 DSH 已知问题调研清单

- **描述**：梳理 DSH 自发布以来的公开问题、社区反馈与本机验证的兼容性问题，生成结构化 Markdown 清单并保存到用户下载目录。  
- **验收标准**：  
  - Given 清单生成完成，When 打开下载目录，Then 存在 `DSH-KNOWN-ISSUES-YYYY-MM-DD.md` 文件；  
  - Given 清单内容，When 查阅任意条目，Then 包含问题描述、影响范围、复现条件、当前状态、规避方式五字段；  
  - Given 清单内容，When 全文搜索，Then 不含对话正文、API Key、OAuth Token、Authorization Header 或模型私有思考内容；  
  - Given 清单覆盖范围，When 核对上游记录，Then 至少包含 pi #7702 / PR #7701、OpenCode #25000 及本机验证的 OpenCode Go DeepSeek reasoning 回放风险。

## 非功能需求

- **安全**：所有诊断与 UI 零敏感数据泄露；清单生成过程不读取或存储对话正文、密钥或认证信息。  
- **兼容性**：插件不与现有 `dsh-compaction-basic`、`dsh-command-compact`、`dsh-compaction-tool-result-pruner` 冲突；可在标准模式与虚拟产品团队模式下共存。  
- **性能**：压缩触发判断开销 < 50ms/step；摘要调用复用当前路由模型，不额外跨服务商传输历史（除非用户显式配置）。  
- **可用性**：压缩状态与失败提示在 DSH 现有 trajectory / compaction row 中可见，无需新增独立面板。

## 非目标（第一版不做）

- 运行状态面板、去敏诊断记录导出、有限安全恢复、已知兼容问题库 UI、DSH 核心修复清单生成器；
- 强制终止卡死流/工具、全局硬上限、持久化状态机、原子恢复、精确成本账单、跨进程断路器；
- 修改或重写上游模型输出内容；
- 跨服务商摘要（除非用户显式配置）。

## 成功指标

- 插件可在 DSH 中独立加载，`node tests/run-all.mjs` 全绿；
- 至少四类路由（DeepSeek 官方、ChatGPT/Codex、OpenCode Go DeepSeek、千问）可配置独立阈值；
- 摘要失败时保留原历史并明确提示，无静默丢上下文；
- 已知问题清单以 Markdown 保存到 `~/Downloads/`，内容结构化、零敏感数据；
- 清单至少覆盖 3 条上游已确认问题 + 1 条本机验证问题。
